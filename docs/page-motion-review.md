Each original illustration is labelled as illustration, not real client footage or an exact representation of campus equipment. No client logos, qualifications, programme details or testimonials have been invented. Approved video and original client media are still required for a documentary/photorealistic treatment.

Public animation has a manual pause control and respects OS reduced motion. No-JavaScript output retains semantic text, links, forms and full story copy. Native scrolling and normal navigation remain in use. Animations are finite except the optional branded values strip, which is paused by the global control and disabled without JavaScript.

Actual browser inspection remains blocked by the saved localhost browser permission. Therefore screenshots, animation smoothness/FPS, actual mobile overflow and browser journey execution are not verified. Source-level Playwright checks are provided; the build, API and HTTP checks are reported separately rather than being presented as visual verification.
