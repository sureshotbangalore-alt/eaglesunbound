# Clean editorial redesign — 2 November 2026

The latest user direction supersedes the animated-world design. Public pages no longer mount Three.js/Anime.js, articulated characters, activity simulations, tactical graphics, moving illustrations, looping values strips or pinned scroll stories. The unused scene components were removed. Dependencies and all exact version locks remain unchanged as requested.

The homepage now uses a static landscape hero, readable headline, restrained booking actions, a quiet values row, an editorial bootcamp introduction, programme imagery, a typographic activity list, founder information and gallery/film links. Theme browsing, mission selection, programme selection, touch/keyboard navigation, catalogue search/filtering, direct activity enquiries and all existing destinations remain available. The former 3D explorer route is retained as a calm image-led theme browser.

Decorative interludes were removed from every inner-page template. Consistent heading scales, body measure, section spacing, warm paper colours, forest accents and aligned sidebars apply across audience, programme, activity, contact, policy and information pages. The footer links remain complete. Illustrative stock images remain labelled; no new claims or fictional client photos were added.

Motion is limited to short heading entrances, brief programme crossfades and restrained interaction feedback. No scroll hijacking or continuous motion is needed. Hero video now requires explicit play. Reduced-motion preferences are respected and content remains visible without JavaScript.

No database, booking/enquiry API, admin capability, SEO configuration, source content inventory or dependency version was removed. Browser regression source was updated to check the absence of scene/canvas elements while preserving programme, theme, booking and no-JavaScript journeys.
